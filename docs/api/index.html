AUTHENTICATION IS NOT AUTHORIZATION

Identity, roles and ownership

Merchant access

A Merchant token does not grant access to arbitrary merchant IDs. Financial operations require an eligible account, verified active merchant and active membership. Payment creation is checked against that scope.

Admin access

Administrators have explicit platform permissions. Shared payment routes accept Admin or Merchant roles, then apply business authorization. There is no public administrator signup.

Browser sessions

Access tokens are RS256 JWTs with issuer/audience validation and a 15-minute lifetime. Browser refresh uses a path-scoped HttpOnly, SameSite=Strict cookie; HTTPS deployments use Secure cookies. Session POSTs require the configured Origin and X-PayMesh-CSRF: 1.

No token entry or authentication is available on this site. Model examples describe shapes, not real users, credentials or payment records. Local loopback cookie configuration is a guarded development exception, not a public deployment setting.
